# 剪映工程工具包 4.3.1

适用于 Windows 10/11 x64。请将整个 ZIP 解压到可写文件夹，再运行中文名称的 EXE；保留 _internal 文件夹。

## 首次运行

界面需要 Microsoft Edge WebView2 Runtime；大部分 Windows 电脑已安装。如无法显示窗口，可双击随包的 Install-Dependencies.cmd 安装缺失组件。

已内置草稿解密器及许可。草稿导入、解密和导出需要兼容的 Windows 剪映；音频导出还需 FFmpeg。首次使用可双击随包 Install-Dependencies.cmd以安装 FFmpeg；安装完成后重新打开本工具。依赖由 winget 从软件发布者下载，安装时可能需要确认。

本版已移除人声分离。解密器不包含剪映的 videoeditor.dll，会使用本机已安装的剪映；实际兼容性受剪映版本影响。写入草稿前应关闭剪映并在草稿副本上操作。

## 本次验证范围

三个程序已在本机清除 Python 环境变量及开发工具 PATH 后启动成窗。PT 的四个内置脚本通过隔离运行时 --help 检查；命名规则的15项回归测试通过。不代表在全新 Windows、真实 Pro Tools 工程或真实剪映草稿上完成业务验收。

依赖版本及第三方许可见 THIRD_PARTY。
